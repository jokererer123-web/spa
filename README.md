# Reina Spa

Luxury massage & wellness web application for **Reina Spa**, Ataşehir / İstanbul.
Turkish-language public site with a scroll-driven hero, plus an owner admin
panel and a dedicated reception/tablet interface for booking management.

## Quick start

```bash
npm install
npm run dev          # http://localhost:3000
```

The app runs **without any configuration**. When Supabase environment
variables are absent it falls back to an in-memory demo store seeded with
realistic guests, packages and bookings, so every screen — including the
dashboards — is fully explorable out of the box.

| Script | Description |
| --- | --- |
| `npm run dev` | Development server |
| `npm run build` | Production build |
| `npm run lint` | ESLint |
| `npm run typecheck` | TypeScript, no emit |
| `npm run test:rules` | Booking business-rule test suite |

## Booking rules

The rules live in one place — [`src/lib/booking-rules.ts`](src/lib/booking-rules.ts) —
and are mirrored by SQL triggers so they hold even if a row is changed
directly in the database.

**Package auto-deduction.** Confirming a booking against a package consumes
exactly one session. The last session flips the package to `depleted`, and a
booking is refused when no sessions remain.

**Cancellation policy.** Cancelling **at least 30 minutes** before the
appointment restores the session automatically. Inside the 30-minute window
the session is forfeited. Cash bookings never generate a phantom credit.

**Critical level alert.** Guests whose balance drops to **2 sessions or fewer**
appear in the *Kritik Paket Seviyesi* list with a pulsing red badge, with a
one-tap call button for renewal follow-up.

Verify them with:

```bash
npm run test:rules
```

## Supabase setup

Optional — the app works without it.

1. Create a project at [supabase.com](https://supabase.com).
2. Run the migration and seed:
   ```bash
   supabase db push
   psql "$DATABASE_URL" -f supabase/seed.sql
   ```
   Or paste [`supabase/migrations/20260817090000_init.sql`](supabase/migrations/20260817090000_init.sql)
   followed by [`supabase/seed.sql`](supabase/seed.sql) into the SQL editor.
3. Copy `.env.example` to `.env.local` and fill in the two values.

The schema includes `profiles`, `customers`, `therapists`, `services`,
`packages`, `customer_packages`, `bookings`, `offers` and `gallery_items`,
with Row Level Security (public read for marketing content, staff-only access
to operational data), the deduction/cancellation triggers, a `critical_packages`
view, and realtime enabled on `bookings` and `customer_packages` so the
reception tablet updates instantly.

## Deployment (Netlify)

[`netlify.toml`](netlify.toml) is committed and ready. Connect the GitHub
repository to Netlify and every push deploys automatically.

1. **Add new site → Import an existing project** and pick this repo.
2. Build command and publish directory are read from `netlify.toml`.
3. Add `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_ANON_KEY` under
   *Site settings → Environment variables* (skip to stay on demo data).

## The hero scroll animation

The hero is a **frame-by-frame canvas scrub**: 41 frames of a therapist
performing a massage stroke, painted to a `<canvas>` as you scroll a 320vh
section.

Keeping it smooth relies on three things:

- Frames are decoded **once** into `ImageBitmap`s up front, with limited
  concurrency so slow connections are not saturated.
- Scroll progress is written to a **ref**, never to React state, so scrubbing
  triggers zero re-renders. A single `requestAnimationFrame` loop repaints only
  when the frame index actually changes.
- Progress is passed through a light Framer Motion **spring** so trackpad and
  iOS momentum scrolling stay fluid.

Only nine of the frames are real images; the rest are generated by
[`scripts/interpolate-frames.mjs`](scripts/interpolate-frames.mjs), which does
motion-compensated interpolation — a coarse-to-fine pyramid block search
estimates the motion field, a forward/backward consistency check plus a
photometric residual test finds pixels that would ghost, and those blend toward
the nearer keyframe instead of double-exposing. Regenerate with
`npm run hero:frames`.

## Tech stack

Next.js 16 (App Router) · React 19 · Tailwind CSS v4 · Framer Motion ·
Lucide icons · Supabase (PostgreSQL, RLS, Realtime) · Netlify

Fonts (Cormorant Garamond, Plus Jakarta Sans) are **self-hosted** via
Fontsource, so builds never depend on reaching Google Fonts and visitors make
no third-party requests.
